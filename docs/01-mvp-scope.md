# MVP Scope

## In Scope

DRIVE: Winter Quest MVP is a coach verified erg quest app.

The MVP includes:

- Coach-created weekly erg quests
- Athlete view of Today's Quest
- Manual PM5 screen photo upload
- Short athlete reflection after the session
- Coach verification or rejection of uploads
- Rewards unlocked only after coach verification
- XP and badge rewards tied to execution quality
- Athlete attributes: Engine, Discipline, Rhythm, and Grit
- Squad mission progress
- River Map progress
- Boathouse progress

## Out Of Scope

The MVP must not include:

- OCR for PM5 photos
- Concept2 Logbook API integration
- Live PM5 Bluetooth connection
- Unity or Godot game clients
- Pure speed rankings
- Global leaderboards based on fastest splits
- Metres-only progression
- Generic workout tracking
- Complex social networking features
- Public athlete profiles
- Coach dashboard beyond what is needed for basic verification, unless explicitly requested later

## Upload Handling

Athletes upload a photo of the PM5 screen as evidence. The system does not read the photo automatically in the MVP.

The coach is responsible for checking whether the upload matches the quest and whether the effort should be verified. Rewards must wait until this verification is complete.

## Reward Timing

No XP, badge, attribute, squad, River Map, or Boathouse progress should be awarded from an unverified upload.

This is non-negotiable. DRIVE rewards honest, coach verified effort.

## MVP Success Criteria

The MVP is successful if it helps a squad run winter erg training with:

- Clear weekly quests
- Honest athlete submissions
- Useful reflections
- Coach verification
- Progress that rewards execution quality
- A serious but fun training identity

## Scope Control

Do not add future integrations or game systems just because they are mentioned in the product direction. Future possibilities are not MVP tasks.

If a requested change is not clearly connected to the MVP loop, stop and ask for confirmation before implementing it.
