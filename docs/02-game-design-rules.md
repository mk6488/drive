# Game Design Rules

## Design Intent

DRIVE should make good rowing training feel earned, visible, and shared. The game layer must support better erg execution, not distract from it.

Use a serious but fun tone. Athletes are 14 to 18, so avoid babyish language, empty hype, or gimmicks that feel like they belong in a children's app.

## Reward Quality

Game systems should reward:

- Holding the requested pace band
- Respecting the requested rate
- Consistent splits
- Completing the intended training stimulus
- Honest evidence uploads
- Reflections that show learning
- Improvement against the athlete's own previous work
- Coach verified effort

## Avoid Bad Incentives

Do not design systems that reward:

- Fastest split alone
- Most metres alone
- Training through pain or injury
- Dishonest uploads
- Sandbagging targets to collect easy rewards
- Public comparison that humiliates slower or newer athletes
- Bad technique hidden behind impressive output

## Core Systems

### Today's Quest

Shows the current coach-set session and what good execution means for that session.

### Reflection

Keeps athletes thinking about training quality. Reflections should be short and useful, not a diary burden.

### Coach Verification

Turns submitted work into trusted progress. Verification is a core game mechanic, not admin decoration.

### Squad Missions

Give the squad a shared goal that can be advanced by verified effort. Squad progress should not depend only on the fastest athletes.

### River Map

Represents journey progress through the winter block. It should feel rowing-specific and progression-based, not like a generic level map.

### Boathouse

Represents squad or athlete development through earned upgrades. Upgrades should connect to training habits and rowing identity.

## Badges

Badges must mean something. A badge should represent a specific training behaviour, verified achievement, or improvement pattern.

Do not add badges just to fill a collection screen.

## Leaderboards

Pure speed leaderboards are not part of the MVP.

If ranking is ever introduced, it must be designed around quality, improvement, consistency, or squad contribution, and must be explicitly approved before implementation.

## Agent Warning

Do not add mini-games, currencies, pets, loot boxes, avatar shops, streak pressure, or unrelated game loops without explicit approval. DRIVE is a rowing training product first.
