# Definition Of Done

Future Cursor agents must check this list before considering a substantive DRIVE task complete.

## Completion Checklist

- The task stayed inside the DRIVE brief.
- No unrequested features were added.
- No unrelated files were changed.
- Screens stayed UI only.
- Business logic stayed in services.
- Firebase access stayed in repositories or services.
- Reward logic stayed in the reward engine.
- Unverified submissions did not unlock rewards.
- Junior safeguarding was respected.
- UK English was used.
- Typecheck and lint were run once the app exists.
- Changed files were summarised.
- Product fit was explained.

## Completion Note

Every final task summary should explain how the change supports DRIVE: Winter Quest as a serious but fun junior rowing app that rewards coach verified execution quality.
